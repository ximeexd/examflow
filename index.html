Справочник ФИПИ

Формулы сокращенного умножения
• (a + b)² = a² + 2ab + b²
• (a - b)² = a² - 2ab + b²
• a² - b² = (a - b)(a + b)
• (a + b)³ = a³ + 3a²b + 3ab² + b³
Свойства степеней
• aⁿ · aᵐ = aⁿ⁺ᵐ
• aⁿ / aᵐ = aⁿ⁻ᵐ
• (aⁿ)ᵐ = aⁿᵐ
• a⁰ = 1 (a ≠ 0)
Орфоэпический минимум
• тОрты (не тортЫ)
• звонИт (не звОнит)
• квартАл (не квАртал)
• каталОг (не каталОг)
Теорема Пифагора
В прямоугольном треугольнике:
c² = a² + b²
где c — гипотенуза, a и b — катеты
